## 🌌 DigiTantra — The Future of Tech Education

**DigiTantra** is a modern, **AI-powered online learning platform** designed to demonstrate how next-generation technologies can redefine technical education.

The platform combines **Generative AI**, **immersive 3D web experiences**, and **cloud-native infrastructure** to automate content creation, enhance learner engagement, and scale efficiently.

Built using **Next.js**, **Firebase**, and **Google’s Generative AI (Genkit)**, DigiTantra features a futuristic **glassmorphic UI**, **dynamic 3D animations**, and **AI-driven intelligent systems**, making it both a **research-grade project** and a **production-style application**.

## ✨ Key Features

### 🤖 Generative AI Content Creation
- Server-side **Genkit flow**
- Powered by **Google Generative AI (Gemini models)**
- Automatically generates **complete, high-quality blog posts** from a single user-provided topic
- Structured and deterministic outputs suitable for real-world applications

---

### 🔮 Dynamic 3D Animated Backgrounds
- Immersive, page-specific **3D environments**
- Built with **Three.js** and **@react-three/fiber**
- Enhances user experience with futuristic visuals and motion

---

### 🔐 Secure User Authentication
- Complete authentication system using **Firebase Authentication**
- Secure sign-up and login flows
- Designed for scalability and production-level access control

---

### 💬 Conversational AI Chatbot — *AI Saarthi*
- Interactive front-end chatbot powered by **Google AI**
- Provides **context-aware responses** to user queries
- Acts as an intelligent assistant for instant learning support

---

### 💎 Modern Glassmorphic UI/UX
- Fully responsive interface
- Built using **Next.js**, **ShadCN UI**, and **Tailwind CSS**
- Dark theme with neon-glow accents
- Glassmorphic design for a modern, cutting-edge aesthetic

---

### 📊 Interactive Data Visualization Dashboard
- Analytics dashboard built with **Recharts**
- Displays platform metrics and key performance indicators (KPIs)
- Clean, animated charts for effective data interpretation
